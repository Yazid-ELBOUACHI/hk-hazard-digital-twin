# HKUST emblem

`hkust-emblem.svg` contains the unchanged emblem paths extracted from the full HKUST logo (`hkust.svg`), with a fitted viewBox for the small header badge. Colours and emblem proportions are preserved.

Asset source: https://logotyp.us/file/ust-hk.svg
University reference: https://brand.hkust.edu.hk/ (University Emblem)

The emblem belongs to The Hong Kong University of Science and Technology. The adjacent project name identifies this application as a research prototype.
